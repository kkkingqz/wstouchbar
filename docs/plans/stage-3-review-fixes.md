# Исправления повторного ревью этапа 3

Основание: REVIEW-STAGE-3-2026-10-17.md и замечания пользователя от 17 октября.
Изменения выполняются последовательно в stage-3-session; каждый завершённый пункт коммитится и отправляется в origin. Контракты Core/replay не меняются. Локальные ошибки диагностируются, очереди и повторные попытки ограничены. Общая изоляция процессов через cgroups остаётся этапу 4.

### Task 1: Журнал решений
Восстановить непрерывную таблицу D102–D104 и стандартную метку источника D102. Проверить diff и сохранить план. Commit/push.

### Task 2: Наблюдатель каталога
Различать рекурсивные каталоги плагинов и наблюдение за конкретным дочерним именем на существующем предке. Объединять роли при совпадении директорий. Проверить отсутствие reload от посторонних файлов, появление недостающих путей, реальные изменения и замену корня. RED→GREEN, loader suite, commit/push.

### Task 3: Контекст журналирования
Хранить контекст экземпляра из CreateInstance до завершения DisposeInstance. Удалить snapshot из обработки записей; сохранить ограниченную историю. Проверить контекст и очистку, session suite, commit/push.

### Task 4: Событийное ожидание spawn
Заменить периодический опрос в worker/helper и ожидании квоты на ожидание fd/сигналов/уведомления с конечными deadline. Сохранить backpressure, timeout и отмену. Проверить молчащую подписку, заполненный канал и освобождение квоты, effects suite, commit/push.

### Task 5: Потомки spawn
Завершать и собирать усыновлённых потомков, включая setsid, при завершении команды, отмене и смерти сессии. Ограничить ожидание унаследованных pipe при аварийной смерти helper. Проверить потомков, результат и возврат квоты; уточнить D102, effects suite, commit/push.

### Task 6: Локальные ошибки
Изолировать восстанавливаемые ошибки accept с задержкой, ошибки GL с ограниченным восстановлением поверхности, переполнение команд без потери необходимых отпусканий клавиш и таймаут внешней команды. Ctrl+T при полной очереди даёт диагностику. Проверить инъекцией ошибок на реальных границах, control/session suites, commit/push.

### Task 7: Приёмка
Fmt, clippy, workspace tests и нужные интеграционные проверки. Одно независимое ревью всего диапазона; исправить существенные находки одним проходом с регрессиями. Обновить отчёт проверки, commit/push, убрать только собственные временные материалы.
