# Приёмка этапа 1

Дата: 2026-10-11. Приёмка T15 из [плана](../plans/stage-1-core.md).

## Среда и проверенный код

Свежий локальный клон ветки `stage-1-core`, без переноса `target` и прочих
игнорируемых файлов из рабочего каталога. Исходный код: `44a96de`.
Контейнер `docker.io/library/ubuntu:26.04`, Ubuntu 26.04.1 LTS, x86_64.
Rust установлен через rustup внутри контейнера: rustc 1.98.1, cargo 1.98.1.
Системные инструменты сборки также установлены внутри контейнера.

Ядро проверяется с виртуальным временем и поддельными исполнителями.
Приёмка не запускает `touchbard`, пользовательскую службу, процессы из
`spawn` или обращения к Touch Bar. Эти части относятся к следующим этапам.

## Повторение

Обычные проверки и устройство обвязки описаны в [testing.md](../testing.md).
Полная длинная проверка, как в задании CI `proptest-long`:

```sh
PROPTEST_CASES=100000 cargo test --workspace --release --locked -- --nocapture
```

Отдельно свойство I1–I12:

```sh
PROPTEST_CASES=100000 cargo test -p touchbar-testkit --test properties --release --locked -- --nocapture
```

Покрытие и JSON-отчёт:

```sh
cargo llvm-cov --workspace --locked --json --summary-only --output-path target/stage-1-coverage.json
```

## Границы этапа

Готовы модель, чистое ядро, автоматы привязок и testkit. Проверены профили,
жизненный цикл экземпляров, слои и панели, захваты, маршруты клавиш, очереди
действий, отмена и coalesce, подписки, сохранение состояния и replay.
Действующие архитектурные решения, включая D37 и D41–D58, записаны в
[журнале решений](../architecture/decisions.md).

Wasm/WIT, разбор TOML, настоящий рендер, системные исполнители, протокол,
проверка владельца через logind и испытания на оборудовании остаются
в этапах 2–5. Документы этих частей описывают целевую архитектуру.
