## Решения и границы

- **Переполненная подписка.** Unsubscribe перед SubscriptionLost и обычный backoff; backend освобождён, экземпляр жив. Цена ограничения: Постоянно слишком большой snapshot повторяется по backoff, без пересоздания логики.
- **Отказ входа runtime.** LogicError и Error в журнале сохраняют Store. Общие бюджеты Core и runtime должны совпадать; при корректном admission Init не попадает в этот отказ. Цена ограничения: При разных лимитах ядро может повторять Init; это ошибка конфигурации оболочки.
- **Установка результата подготовки.** install принимает Result<PreparedModule, LoadError>, чтобы кешировать также ошибки рабочего потока. Цена ограничения: Загрузчик передаёт результат целиком, а не только успешный модуль.
- **Сброс восстановленного состояния.** D78 утверждён пользователем: сбрасывается весь persisted для Init, конфигурация сохраняется. Цена ограничения: Восстановленные значения не попадут в этот Init; предупреждение сообщает причину.
- **Лимит spawn.lines.** Консервативный бюджет двух потоков, как для spawn.run; политика документирована. Цена ограничения: Некоторые допустимые по фактической длине строки запросы с большим max_output будут отклонены.
- **Ленивый describe.** Остаётся в create в потоке сессии, один раз на ревизию; ревью прямо допускает это. Цена ограничения: Первый create включает время describe, ограниченное hard deadline.
- **Неизменяемость ревизии.** Запись кеша, успешная или ошибочная, имеет приоритет над последующей установкой под тем же ключом, даже результатом другого Engine. Цена ограничения: Исправленный модуль требует новой ревизии или явного удаления старой записи.
- **Тики при загрузке persisted.** Захват действует на весь create, включая загрузку сохранения. Цена ограничения: При медленном чтении тикер продолжает работать до конца create; простой сессии не затронут.
- **Точность epoch.** Сохраняется существующая модель прерываний Wasmtime с миллисекундными тиками. Цена ограничения: Планировщик ОС может увеличить реальную задержку относительно hard_ms.
- **Согласование загрузчика.** Очистка опирается на принятый каталог; поздние результаты рабочих потоков согласует оболочка будущего этапа. Цена ограничения: Неправильное согласование может удержать старый код или удалить нужную для create ревизию.
- **Неподтверждённый fault.** Запись подтверждения живёт до DisposeInstance; штатное ядро выдаёт его при сбое. Цена ограничения: Нарушающий этот протокол вызывающий код может накопить записи.
- **Повтор полного InstanceId.** До подтверждения старого dispose полный id повторно не используется; новые поколения изолированы. Цена ограничения: Нарушение владения поколениями может применить старый dispose к повторно созданному экземпляру.
- **Миграция checkpoint между версиями.** Структура и версия формата состояния не менялись; механизм миграции не расширяется этим исправлением. Цена ограничения: Совместимость продолжения старых дампов при изменении поведения ядра здесь отдельно не доказывалась.
