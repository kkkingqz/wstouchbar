## Открытые вопросы

1. **Esc в наборе F-клавиш** — решаем позже (D9).
2. **Время жизни recovery.** Сейчас маркер в `/run`: recovery переживает перезапуск `touchbard`, но не перезагрузку. Нужно ли сохранять его и после перезагрузки (`/var/lib`)?
3. **`session-grace-ms`.** Значение 2000 мс нужно проверить на железе вместе со временем перезапуска сессии.
4. **Привязка recovery по умолчанию.** Унаследована от исходного проекта: удержание Fn 8 с.
5. **Профиль `default`.** Состав — аналог системного ряда исходного проекта (яркость, громкость, медиа), раскладку нужно согласовать.
6. **Язык документации.** Сейчас документация на русском, README на английском. Для публичного проекта может понадобиться английская версия.
7. **Поддерживаемые версии GNOME Shell** для расширения.
