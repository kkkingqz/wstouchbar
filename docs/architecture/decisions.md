| D37 | `committed` защищает от скрытия, уничтожения экземпляра и смены профиля, но логика может явно отменить запрос (`cancel`) или заменить ожидающий (`coalesce`) | принято (предложено при ревью) |
| D38 | Владелец `touchbard` проверяется по UID клиента и активной сессии seat0 (класс `user`, тип `wayland`/`x11`). `GetSessionByPID` и `XDG_SESSION_ID` не используются, `Hello` не заявляет сессию | пользователь (из предложенных вариантов) |
| D39 | Одновременные графические сессии одного пользователя на seat0 не поддерживаются, сессия Touch Bar работает с активной | пользователь (из предложенных вариантов) |
| D40 | На время блокировки экрана (`LockedHint`) Touch Bar в `native`, расширение отвергает `Shortcut` и `LaunchApp` | пользователь (из предложенных вариантов) |
| D41 | Вызовы хоста `LogicCall::Init { config, persisted }` и `LogicCall::Handle(LogicEvent)` имеют общий `CallId` и один слот. После проверки `LogicDescribed` ядро вызывает `Init`; только успешный ответ переводит `Loading` в `Hidden`. WIT-события не меняются | пользователь |
| D42 | Изменение `when`: `true → false` сразу завершает `while-held` и сбрасывает незавершённый жест; `false → true` требует нового физического триггера. Удерживаемая клавиша сама привязку не активирует | пользователь |
| D43 | При native и отзыве ядро может выдавать завершающие `released`, но не новые `pressed` и кадры. `touchbard` независимо отпускает введённые клавиши перед native, отзывом и закрытием соединения, даже если сессия зависла | пользователь |
| D44 | Загрузчик передаёт стабильную ревизию содержимого плагина в `PluginSpec`. При прежней ревизии экземпляр сохраняется; изменение ревизии владельца набора или поставщика общей логики пересоздаёт затронутые экземпляры. Сохраняемые поля остаются | пользователь |
| D45 | `LogicError{instance, call, message}` сообщает обычный `Err`: у `handle` журнал и продолжение очереди без изменения состояния, у `init` — `Faulted` с backoff. `InstanceFault{instance, reason}` сообщает ошибку загрузки или `describe` до появления `CallId`, также с backoff | пользователь |

| D46 | Pending профиля ждёт завершения захватов и физических Action-вызовов (в очереди и выполняющихся) своей поверхности. Исходный deadline 1500 мс не продлевается; по нему незавершённые вызовы отбрасываются, а уже принятые committed-запросы сохраняются по D37 | пользователь |

| D47 | Для scrubber рендер передаёт область, ширину содержимого и геометрию элементов с record_key. Ядро хранит смещение, подсветку и выбор отдельно от состояния плагина, возвращая их в Scene. Свободная прокрутка, выбор при отпускании; cancel восстанавливает состояние до жеста. value-changed передаёт смещение в базовых единицах, selected — record_key | пользователь |

| D48 | Виджеты панели используют runtime и состояние владельца набора. Открытие/закрытие панели не создаёт отдельный экземпляр и не скрывает владельца | пользователь |
| D49 | Хост хранит исходный захват и якорь в приватных данных физического вызова, WIT не меняется. Transient требует живой исходный захват; persistent может открыться после Up с прежним якорем | пользователь |
| D50 | Layout явно передаёт границы слотов и активной панели. Region — слот владельца, full — поверхность, anchored — исходный прямоугольник виджета; рендер вычисляет окончательные границы | пользователь |

| D51 | На поверхности одна копия слоя каждого SetRef: независимые удержания (источник, привязка) и флаг постоянного включения. Ended снимает только своё удержание; слой снимается после последнего удержания и выключения флага. Новая активация поднимает слой наверх | пользователь |
| D52 | Native/отзыв сбрасывает автомат источника этой поверхности и его удержания, включая явные цели all/surfaces; другие источники продолжают работать. Native-цель теряет удержания и не восстанавливает их до нового физического срабатывания. Явные цели допускают изменение других поверхностей | пользователь |

| D53 | При выполнении key.down требуется живое Visible-поколение владельца; иначе запрос завершается Unavailable без нажатия и без отмены committed. Key.tap сохраняет committed-семантику, пока доступен маршрут ввода | пользователь |

| D54 | Ключ сохранения: плагин-владелец набора, стабильное имя поверхности и область ProfileSlot(slot, set) или Layer(set). Профиль использует путь plugin/surface/slots/slot/set.json; слой — plugin/surface/layers/set.json. Общий поставщик wasm не меняет владельца состояния | пользователь |
| D55 | CreateInstance передаёт стабильный ключ хосту; LogicDescribed возвращает загруженные поля. Ядро фильтрует их по схеме до Init; актуальный кеш ядра имеет приоритет над диском при пересоздании. Отложенный Persist адресуется стабильным ключом и переживает уничтожение экземпляра; WIT не меняется | пользователь |

| D56 | Локаль передаёт оболочка через Input::Locale, до этого C. ContextChanged формируется после успешного Init и принятого Layout со слотом; геометрия и responsive-вариант — из Layout, тема — из фактов. Повторяется только при изменении; пустой representation означает базовое представление | пользователь |

| D57 | Конечные f32/f64 остаются JSON-числами. NaN и бесконечности передаются строками f32:XXXXXXXX или f64:XXXXXXXXXXXXXXXX с точными IEEE-битами, включая знак и payload NaN. Общая кодировка применяется к сериализуемым числовым полям, версия дампа — 2; проверки допустимости значений ядром сохраняются | пользователь |

| D58 | Для проверки I1/I9 чёрным ящиком ядро выдаёт диагностический CaptureFinished с исходным захватом и Up либо Cancel(reason), а CoreSnapshot содержит текущие key_leases: владелец, поверхность, клавиша, маршрут. Это наблюдения, исполнители их не выполняют; WIT не меняется. Версия дампа — 3 | пользователь |

| D59 | При скрытии уже поставленные Cancelled сохраняются и доставляются живому экземпляру своего поколения перед Hidden, даже если статус уже Hidden. Это исключение для cleanup из I5; новые действия скрытому экземпляру запрещены. Физическое освобождение ресурсов и уничтожение не ждут callback; Faulted/Disposed события не получают | пользователь |
| D60 | Cancel отзывает разрешение исходного касания на открытие панели: приватный контекст удаляется у его очередных и выполняющихся вызовов, сам Cancelled также не разрешает Open. Persistent после обычного Up по D49 остаётся допустимым. Уже принятые committed-запросы сохраняют правила D37 | пользователь |

| D61 | При истечении Pending профиля старые физические вызовы отбрасываются по D46, но уже поставленный Cancelled сохраняется. Для касаний, завершённых до deadline и имеющих отброшенную работу, ставится один Cancelled(Profile) без разрешения панели; cleanup не запускает старые Activated/Released. Доставка живому экземпляру не задерживает смену профиля | пользователь |

| D62 | Новый until-hidden от Hidden отклоняется с предупреждением без EffectDone, до coalesce и выделения RequestId. Фоновые действия скрытой логики требуют committed. Принятый при Visible until-hidden по-прежнему получает cancelled при скрытии | пользователь |

| D63 | Уточнение D54: профильный ключ включает набор; путь plugin/surface/slots/slot/set.json. Один набор в одном слоте разных профилей разделяет состояние. logic_config в ключ не входит. Полное состояние — версия 3, дамп — версия 4; старые версии явно отвергаются | пользователь |

| D64 | Multi-tap и sequence непрерывны: постороннее нажатие между нажатиями или шагами сбрасывает распознавание. Новая серия может начаться после сброса; для sequence сама сбросившая клавиша может начать первый шаг, если подходит ему. Клавиши ожидаемого шага и аккорда сохраняют допустимые переходы | пользователь |

| D65 | Уточнение I10: завершение прежнего Pending профиля на входе отказа — допустимая перераскладка, как на нейтральном входе. Checker допускает только удаление заменённых профильных экземпляров: прежняя цель Pending стала active, Pending снят, размещение удалено и выдан DisposeInstance. Состояние и статус сохранившихся экземпляров неизменны; удаление слоя или сохранённого размещения этим исключением не разрешается. Порядок синхронизации ядра сохраняется | пользователь |

| D71 | Runtime проверяет время вызова, память и общий размер обновления (`LogicFault`); перевод из WIT отбрасывает непредставимые элементы с предупреждением; поэлементные проверки остаются в ядре. Лимиты хранятся в `touchbar-logic-types`, `CoreConfig::default()` берёт значения оттуда без изменения формата | принято |
| D72 | `controls` открывает панели встроенными `expanded_panel` и `press_and_hold_panel`, логика отвечает только за значения и действия | принято |

| D74 | Вызовы логики синхронны; разрешены служебные потоки тикера epoch и внутреннего работника встроенного кеша Wasmtime. Это уточнение ограничения L6 сохраняет D70 | пользователь; 2026-10-12 |

## Реализация этапа 2, 2026-10-13

| # | Решение | Кто |
|---|---|---|
| D77 | Отдельный настраиваемый `max_table_elements = 65 536` ограничивает сумму начальных размеров и роста всех wasm-таблиц одного экземпляра. Линейная память остаётся отдельным бюджетом 16 МиБ; неудачный рост возвращает резерв таблицы, trap после отказа изолирует экземпляр с причиной `table` | пользователь; 2026-10-13 |
| D78 | Если полный Init с допустимым `logic_config` и восстановленным состоянием превышает бюджет вызова, ядро отбрасывает всё восстановленное состояние с предупреждением и сохраняет конфигурацию. Конфигурация, не помещающаяся даже без состояния, отвергается при приёме каталога | пользователь; 2026-10-14 |

Контракт и семантика committed не изменялись. Slider завершает drag на Activated согласно 03-core. Приёмка — [stage-2.md](../validation/stage-2.md).

## Открытые вопросы

1. **Esc в наборе F-клавиш** — решаем позже (D9).
2. ~~**Время жизни recovery.**~~ Закрыт: маркер в `/run` (D121).
3. **`session-grace-ms`.** Значение 2000 мс нужно проверить на железе вместе со временем перезапуска сессии.
4. ~~**Привязка recovery по умолчанию.**~~ Закрыт: удержание Fn 8 с (D120).
5. **Профиль `default`.** Состав — аналог системного ряда исходного проекта (яркость, громкость, медиа), раскладку нужно согласовать.
6. **Язык документации.** Сейчас документация на русском, README на английском. Для публичного проекта может понадобиться английская версия.
7. **Поддерживаемые версии GNOME Shell** для расширения.
8. **Окно без фокуса в GNOME** для поверхности `window`: поверхность внутри Shell через расширение или окно, которому запрещён фокус. Нужно исследование до реализации ([16-surfaces.md](16-surfaces.md)).
9. **Плотность Touch Bar.** Пороги жестов пересчитаны из пикселей в предположении около 6 px/мм. Нужно измерить на железе и заполнить таблицу моделей.
