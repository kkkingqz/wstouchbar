# Этапы работ

Работа идёт в этом репозитории. Код из исходного проекта переносится копированием с указанием источника (коммит `d2f9dfd` ветки `t2-appletbdrm`) в описании коммита. Исходный проект остаётся эталоном поведения, пока новая версия не достигнет паритета.

| Этап | Содержание | Готово, когда |
|---|---|---|
| **0. Документ** | эта архитектура, список паритета, открытые вопросы | документ согласован |
| **1. Ядро** | `touchbar-core`, `touchbar-bindings`, `touchbar-testkit`, property-тесты инвариантов, сценарии из найденных багов | инварианты I1–I12 проходят на 10⁵ случайных последовательностей |
| **2. Логика** | `wit/logic.wit`, `touchbar-logic-types`, `-runtime`, `-sdk`, формат наборов и манифеста (`touchbar-sets`, D66), перенос плагина `controls` | `controls` проходит тесты логики в testkit |
| **3. Сессия** | дерево UI из наборов (`touchbar-sets`), перенос `touchbar-ui` и `touchbar-layout`, исполнитель действий, `touchbar-audio`, поверхность `headless` и симулятор, `touchbarctl render/status` | `controls` работает в симуляторе, эталонные PNG |
| **4. touchbard** | протокол v2, рефакторинг `touchbard`: режимы, владение по logind, recovery, сон, мост Fn, затемнение | на железе: чек-лист пунктов 1, 3–7 ([13-testing.md](13-testing.md)) |
| **5. Содержимое** | `touchbar-media`, `touchbar-open`, `touchbar-apps`, API рабочего стола, бэкенд GNOME и расширение, плагины `system`, `media`, `browser`, `profile-*` | весь список паритета v1 на железе |
| **6. Выпуск** | `touchbarctl` полностью, `xtask install/deb`, PKGBUILD, CI, Releases, переход wsconfig на пакет с удалением `ws-touchbar-fn` | установка `.deb` на чистую систему и на рабочую машину через wsconfig |

## Паритет v1

Функции исходного проекта, которые должны работать в первой версии:

| Функция | Где |
|---|---|
| Громкость: ползунок, значок без звука, снятие mute ползунком, обновление при внешних изменениях | `controls/volume` |
| Микрофон: переключение, состояние, панель громкости с микрофоном | `controls/microphone` |
| Яркость экрана (не Touch Bar): ползунок, обновление при внешних изменениях | `controls/brightness` |
| Медиа: play/pause, следующий, предыдущий; шкала с перемоткой касанием; выбор плеера по правилу macOS | `media/transport`, `media/timeline` |
| Браузер: назад, вперёд, обновить | `browser/navigation` |
| F1–F12 по Fn | `system/fkeys` + привязка |
| Профили: по умолчанию, браузер, медиаплеер, браузер с активным медиа | `profile-*` |
| Нативный режим во сне, без сессии и в recovery; recovery удержанием Fn 8 с | `touchbard` |
| Мост Fn и затемнение (вместо `ws-touchbar-fn`) | `touchbard` |
| Выбор GPU, перерисовка только изменённых областей | рендер |

## После v1

Поверхность `window` (окно Wayland на сенсорном мониторе, [16-surfaces.md](16-surfaces.md)), батарея и профиль питания (`controls`), now-playing (`media`), офис (B/I/U), command-deck, capture, бэкенды Hyprland и Omarchy, workspaces, RPM, репозиторий t2linux, `http`, `file`, `clipboard` и `notify` в каталоге действий, триггеры касанием полосы.
